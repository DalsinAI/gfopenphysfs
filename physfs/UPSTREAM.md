# PhysicsFS as released

These files are PhysicsFS 3.2.0, unchanged: icculus/physfs, tag
`release-3.2.0`, commit eb3383b532c5f74bfeb42ec306ba2cf80eed988c, from its
`src/` (the other platforms' files left out; posix and unix kept for the
host check), with its LICENSE.txt.

The AmigaOS changes are not here: the platform is `amiga/`, the header
changes are `patches/`, and `build-amiga.sh` applies them to a copy.
